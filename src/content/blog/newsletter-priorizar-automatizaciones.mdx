# Como priorizar que automatizar primero

La pregunta no es solo que proceso se puede automatizar. Casi siempre hay varios. La pregunta buena es cual conviene tocar primero para reducir coste, errores o dependencia de personas clave.

Una forma sencilla de decidirlo es puntuar cada proceso con cuatro criterios.

## 1. Frecuencia

Cuantas veces se repite al mes. Un proceso pequeno que ocurre cada dia suele pesar mas que una tarea grande que aparece dos veces al ano.

## 2. Tiempo manual

Cuantos minutos reales consume cada repeticion, incluyendo buscar datos, copiar informacion, revisar errores y avisar a otras personas.

## 3. Riesgo

Que pasa si alguien se equivoca o se olvida. Si afecta a ventas, facturacion, renovaciones, entregas o soporte a clientes, el impacto comercial es mayor.

## 4. Trazabilidad

Si hoy no puedes saber quien hizo que, en que estado esta algo o por que se tomo una decision, ahi hay una oportunidad clara para construir una fuente de verdad.

## Regla practica

Empieza por el proceso que combine repeticion alta, tiempo manual alto y poca trazabilidad. No suele ser el mas vistoso, pero normalmente es el que libera capacidad antes.

Si quieres poner numeros a esto, usa el diagnostico de procesos y revisamos que automatizacion tendria mas sentido construir primero.
