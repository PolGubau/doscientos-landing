# Software para administradores de fincas: como ordenar incidencias

En una administracion de fincas, el problema no suele ser falta de trabajo. Es falta de visibilidad.

Una incidencia puede empezar con un WhatsApp, seguir con una llamada, requerir fotos, pasar a un proveedor, esperar presupuesto y acabar en una factura. Si no hay una fuente de verdad, el equipo pierde tiempo reconstruyendo que paso.

## Senales de que la operativa esta desordenada

- Hay incidencias abiertas que nadie sabe en que estado estan
- Los propietarios preguntan antes de que el equipo tenga respuesta
- Las fotos, presupuestos y facturas viven en carpetas distintas
- Los proveedores se persiguen manualmente
- Cada finca tiene informacion repartida en emails y chats

## Que deberia resolver el sistema

### 1. Una ficha por finca

Cada finca deberia agrupar incidencias, propietarios, proveedores, documentos y tareas pendientes.

### 2. Incidencias con estado real

No basta con "abierta" o "cerrada". Estados utiles:

- recibida
- pendiente de proveedor
- pendiente de presupuesto
- aprobada
- en ejecucion
- pendiente de factura
- cerrada

### 3. Documentos vinculados al contexto

Un acta, una foto o una factura deberian estar unidos a la finca o incidencia correcta.

### 4. Responsables y proxima accion

Cada incidencia necesita saber quien la lleva y que debe pasar despues.

## El primer modulo recomendado

Antes de crear un portal para propietarios, suele ser mejor construir el panel interno. Si el equipo no tiene control, exponerlo fuera solo amplifica el caos.
